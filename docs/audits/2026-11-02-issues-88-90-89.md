# Issues #88, #90 and #89

Implemented on `fix/issues-88-90-89`. The owner authorized committing, pushing
and opening a review PR on 2026-11-02, together with #92. No installed-app
replacement or release is included. The combined-release hold remains active.

## Changes

- **#88:** the update confirmation measures its buttons before wrapping the
  explanation. The strip grows with its text, keeps the actions vertically
  centered beside it, and moves them below it when less than 200dp remains for
  text. Existing wording and actions are preserved.
- **#90:** a previously created workspace tab missing from the tab manager counts
  as down. Its sidebar status reads stopped, preserving Failed for failed runs.
  Runs with no open members remain hidden. The status count now reads `N/M UP`
  rather than calling every member a server; drawing and width measurement use
  the same label.
- **#89:** restoration sends the allowlisted agent name and quoted exact UUID to
  the ready shell, which resolves commands through its own PATH. Kaze no longer
  rejects a resume because the GUI process cannot find the executable. Existing
  ID, agent, transcript and shell validation, readiness handling, cancellation,
  and single-submission behavior remain in place. Missing commands and agent
  errors appear in the restored terminal through normal command output.

## Verification

The three regression tests first reproduced the original failures: unwrapped
confirmation text, a closed member counted as up, and a rejected resume under a
minimal app PATH. They pass with the changes.

- `go test -timeout=5m ./...` and `go vet ./...`.
- `go test -race -timeout=5m ./internal/ui`.
- Native macOS build; Windows amd64 and arm64 cross-builds with cgo disabled.
- Confirmation geometry tests at content widths of 320, 360, 560 and 1000px:
  complete wrapping, text/button containment, separate text/action areas,
  stacked narrow actions, and side-by-side wide actions.
- Headless Gio GPU renders of the confirmation at narrow and wide widths in
  Midnight and Washi. Text wraps without colliding with either button. Temporary
  capture code was removed; the local composite is `/tmp/kaze-confirm-layout.png`.
  No native window was opened or global input injected.
- A native zsh subprocess uses an isolated `.zshrc` to add temporary fake Claude
  and Codex commands to PATH. Both receive the exact resume arguments despite
  the parent app's minimal PATH. Removing each fake command produces a visible
  shell error. No real agents or conversations were launched.
- Existing restoration tests still cover waiting for prompt readiness, one-time
  submission, typing cancellation, saved identities and update handoff ownership.
