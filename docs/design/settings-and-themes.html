kaze: five themes

Each theme changes the window (tabs, bars, toasts) and the terminal's own 16 colors, so Claude Code, git and ls match. Same sample in every card: Claude output, a git status, an alert toast and the usage bar.

The settings page

Opens as its own tab (gear button in the title bar, or Ctrl+,). Changes apply at once and are saved to the config file. Pick a section and a theme to preview.
