Includes Kaze and every shell, agent and server it started. CPU 100% means all cores busy. RAM is memory in use (physical footprint). Updates every 2 s, paused while minimized.

What it measures

Kaze plus everything it started (shells, Claude, Codex, dev servers). The card splits it: Kaze itself first, then one row per session, with workspace tabs and scratch shells counted in the session they belong to.

CPU meaning

A share of the whole machine: 100% means every core is busy. Same rule on macOS and Windows (Windows Task Manager style), so the meter never goes past full. The card names the core count.

Colours

Meter is accent while normal, amber at 50% or more, red at 80% or more, judged on the average of the last few readings so one spike doesn't flash. RAM has no meter, just the size.

Narrow windows

The CPU label drops first, then the meter, leaving 4% · 1.8 GB. The card stays the same. No new timer: it shares the 2 s memory reading.
