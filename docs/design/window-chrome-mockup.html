What changes

  • One bar on both platforms. On macOS, Kaze stops using the system title bar and draws its own. The real traffic lights stay, inset into Kaze's bar. On Windows, Kaze already draws its own; it gets the same layout.
  • The sidebar's icon row moves up into the title bar, above the sidebar. The sidebar starts with the filter, so it gains a row.
  • The session you're in is named in the bar: repo, title, command and state. It replaces "kaze · zsh".
  • A real search field in the middle opens the palette, showing its key.
  • On the right: scratch shell, Agents (with its badge) and Settings. On Windows the minimize, maximize and close buttons follow, redrawn thin, with a red close on hover.

Notes

  • The title bar is 42px (today: macOS 28px system bar plus a 36px icon row; Windows 38px).
  • Empty space in the bar still drags the window, and a double click maximizes it on both.
  • Feasible on Mac: Gio can open a frameless window with a full-size content view. Kaze then turns the native traffic lights back on with a small macOS call (to check during the build).
  • No gradients. Theme colours only, so all five themes work.
  • The + for a new session moves to the title bar, above the sidebar; the filter takes the full width.
  • In a narrow window the status bar drops tabs, then memory, then server counts, before anything gets cut.
