Built around the agent.
Still just a terminal.

Run Claude Code in as many sessions as you like. Kaze keeps track,
so you only look when something needs you.

◐

A sidebar of sessions.

Sessions group by repo, worktrees included. Each row shows its folder, branch, the lines changed and the slash command it runs, plus a plain needs you, running or done.

⇥

Jump to what’s waiting.

Next waiting takes you to the next session that needs an answer, in sidebar order. A toast and an optional chime tell you when Claude asks, even while you work elsewhere.

▣

Floating panes.

Watch a server’s log without leaving your Claude session. Click a workspace member and it floats over the session: drag it, resize it, type into it, or expand it to the main view.

›_

A scratch shell, per session.

Press Ctrl ` for a quick shell in the session’s folder. Press it again to hide it; it keeps running, with its screen, until the session closes.

⋔

See every subagent.

When Claude hands work to subagents, each one shows under its session with its task and current step. Click one to watch its steps live and read its report, or press ⌘ ⇧ A for a board of every subagent: running, waiting on you and done.

⌕

One key finds everything.

⌘ K opens the palette: waiting sessions first, then every session and server, your Claude Code skills and slash commands, and Kaze’s own actions.

Release by release.

Kaze checks for new versions by itself and updates in place from Settings, Updates.

  1. 0.14LatestOct 31, 2026

    See what your subagents are doing

    • Subagents in the sidebar: each session lists its subagents with their task, how long they’ve run and the step they’re on.
    • A live pane per subagent: click one to follow its steps as they happen and read its report when it finishes, with a Copy report button.
    • The agents board: every subagent in every session, in running, waiting on you and done. Open it with the Agents button, the status bar, the palette or ⌘ ⇧ A (Ctrl Shift A on Windows).
    • Setup in one click: Settings, Agents checks the three new Claude Code hooks and Fix adds them, showing the change first.
    • Fixed: pressing Command on its own no longer types a ⌘ into the terminal.
  2. 0.13Oct 31, 2026

    Claude Code and Codex, side by side

    • Agents settings: shared alert controls, with separate setup checks for Claude Code and Codex.
    • Codex hooks: see when Codex needs you, is running or is done. Interrupting Codex clears its running state without a done alert.
    • Know which agent: session rows and the palette show Claude or Codex beside the command, including Codex’s $skill names.
    • Setup with a preview: Codex Fix asks before writing, backs up existing hooks, and leaves your other hooks and config alone. Then review and trust Kaze’s hooks with /hooks in Codex.
    • A refreshed lander: native Kaze 0.12 screenshots, an Appearance view in the gallery, and a mobile layout with roomier navigation and buttons.
  3. 0.12Oct 31, 2026

    A redesigned settings page

    • A new look: settings sit in cards, with a clean UI font and new controls. Monospace is kept for keys, paths and commands.
    • Appearance: theme cards that preview each theme, a live preview of your theme, font size and cursor, and cursor shapes you can see.
    • Workspaces: one card per workspace with its state, and each tab’s folder, commands and start condition at a glance.
    • Claude: your Claude Code setup first, with a Connected or Missing mark per hook and a one-click Fix.
    • Shortcuts: grouped, drawn as key caps, and searchable.
    • Updates: its own page, with the update status, progress while it downloads, and the automatic-check switch.
    • About: roomier, with your version, platform and a Report an issue button.
    • New icons for the sidebar, search, scratch shell and settings buttons, drawn as one matched set.
  4. 0.11Oct 31, 2026

    Downloads and updates

    • Download Kaze for macOS (Apple Silicon and Intel) and Windows, no Go needed.
    • Updates in place: Kaze checks GitHub once a day, shows “Update” in the status bar, and installs a new version with one click after asking. Each download is checked against the release’s checksums.
  5. 0.10

Opening Kaze
the first time.

Kaze isn’t signed by Apple or Microsoft yet, so your computer asks you to confirm it once.
It takes a minute, and you won’t see it again, updates included.

macOS

  1. Download and unzip. Click Download for macOS. Safari unzips it for you; otherwise double-click Kaze-macOS.zip in Downloads.
  2. Drag Kaze into Applications. Open it from there, not from Downloads: macOS runs apps from Downloads in a read-only copy, and Kaze can’t update itself there.
  3. Open it, then click Done. macOS says “Kaze” Not Opened. Apple could not verify “Kaze” is free of malware. Click Done, not Move to Trash.
  4. Allow it in Privacy & Security. Open System Settings › Privacy & Security and scroll down to “Kaze” was blocked to protect your Mac. Click Open Anyway and confirm with your password or Touch ID.
  5. Click Open. Kaze starts, and macOS won’t ask again.
Or skip steps 3 to 5 in Terminal, after step 2
xattr -dr com.apple.quarantine /Applications/Kaze.app

Windows

  1. Download and unzip. Click Download for Windows (or the ARM build on a Windows on ARM PC). Right-click the zip and choose Extract All.
  2. Keep kaze.exe in a folder of your own, like Documents\Kaze. Not Program Files: Kaze replaces its own exe when it updates.
  3. Run kaze.exe. If SmartScreen says Windows protected your PC, click More info, then Run anyway.
  4. That’s it. Pin it to the taskbar if you like; Windows won’t ask again.

If Smart App Control is on, Windows blocks unsigned apps with no way past it. Build Kaze from source instead.
